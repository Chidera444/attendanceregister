# Attendance Register

A simple web app to record student attendance for a lecture. Built using plain HTML, CSS, and JavaScript (no frameworks).

## Features

- Add student names
- Mark student as Present / Absent
- Display attendance list in a table
- Count total present
- Count total absent
- Search student names
- Save attendance using Local Storage
- Edit attendance record

## File Structure

```
attendance-register/
│
├── index.html      # Main HTML file (page structure)
├── style.css        # CSS file (styling)
└── script.js         # JavaScript file (logic/functionality)
```


## How to Use

1. Type a student name in the input box and click **Add Student**.
2. Click **Mark Present/Absent** next to a student to change their status.
3. Use the search box to quickly find a student by name.
4. Click **Save Attendance** to store the current list in your browser's Local Storage.
5. Click **Load Saved Attendance** to bring back a previously saved list (this also happens automatically when the page loads).
6. Click **Edit** to change a student's name, or **Delete** to remove them from the list.

## Notes

- Attendance data is stored in the browser's Local Storage, so it stays saved even after closing the tab, but only on the same browser and device.
- No backend or database is used — this is a beginner-friendly, front-end-only project.
